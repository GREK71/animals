# 서도윤 비주얼 기준 | 수인 쉐어하우스 기획 적용분

작성일: 2026-10-27
출처: 이전 기획(「지구연구중」)의 도윤 외형 가이드. 세계관 문서 원칙에 따라 **얼굴 기준만** 가져오고, 과거 세계관·집(HOME v1.0)·소품(뜨개질, 후추)·이미지 프롬프트는 이 기획에 적용하지 않는다.

## 1. 가져오는 것 | 얼굴 기준

- 한국인 남성. 설정 나이 28세이며, 얼굴 인상은 20대 후반에서 30대 초반 사이로 보인다.
- **쌍꺼풀이 거의 없는 무쌍 눈.** 가장 중요한 식별 기준.
- 약간 큰 코, 두껍지 않은 입술.
- 자연스럽게 헝클어진 짙은 머리.
- 자연스럽고 현실적인 외모. 아이돌·AI 미남처럼 과도하게 정제하지 않는다.
- 웃으면 평소보다 인상이 확실히 부드러워진다.

레퍼런스 이미지: 이전 기획에서 생성한 도윤 프로필 이미지 2종과 초기 캐릭터 시트. 현재 저장소 `visual/` 폴더에는 이현 이미지 2장만 있고 도윤 이미지는 없다. `visual/서도윤_얼굴.png` 형태로 추가 필요.

## 2. 이 기획에서 바뀌는 것 | 표정 방향

이전 가이드의 기본 표정은 "무표정 또는 생각에 잠긴, 차분하고 약간 경계심 있는 인상"이었다. 수인 쉐어하우스의 도윤은 골든 리트리버 수인으로 매사에 긍정적이고 해맑으며 사람을 잘 따른다. 따라서:

- **얼굴 생김새(무쌍, 코, 입술, 머리)는 유지**하고 **표정의 기본값만 바꾼다.** 기본은 열려 있고 밝은 표정, 감정이 얼굴에 바로 드러나는 솔직함.
- 레퍼런스 이미지가 차분한 표정이어도 생성 시 "같은 얼굴, 다른 표정"으로 지시한다. 얼굴을 재해석하지 않는다.
- 이전 가이드의 "차분·경계심" 인상은 이현 쪽 성격에 가깝다. 두 인물이 비슷해 보이지 않도록 도윤 쪽 표정 지시는 항상 밝은 방향으로 둔다.
- 모델 일을 할 때만 카리스마 있는 절제된 표정을 쓴다. 이때는 이전 가이드의 무표정 인상이 자연스럽게 활용된다.

## 3. 유지해도 되는 것 | 의상

- 평범한 후드티, 티셔츠, 캐주얼 아우터 등 현실적인 일상복. 이전 가이드와 충돌 없음.
- 쉐어하우스 장면 기본 홈웨어는 밝은 색(크림, 베이지, 연회색)으로 두어 검정 니트의 이현과 대비한다. (제안, 미확정)

## 4. 적용하지 않는 것

- 「지구연구중」 세계관 전체 (Day 107, 혼자 사는 원룸, 물류센터, 뜨개질, 고양이 후추).
- HOME v1.0 집 구조와 Sims 레퍼런스, HOME 공통 프롬프트, Master Prompt.
- 이미지 타입 분류(SNS형 / 제3자 시점 / 서사적 이미지). 이 기획은 숏폼 영상이 중심이므로 별도 기준을 세운다.
- 첫 게시물 이미지 방향(옆얼굴, 물건 없는 집). 이 기획의 첫 게시물은 EP.01 릴스로 대체.

## 5. 결정이 필요한 것

- **사진·영상 질감 방향.** 이전 가이드는 "스마트폰으로 찍은 듯한 현실적 질감, 영화적 색보정 지양"을 원칙으로 했다. 이 기획도 "실사형"이지만, 채널 전체를 스마트폰 브이로그 톤으로 갈지 조금 더 정돈된 웹드라마 톤으로 갈지는 미정이다. 이현 비주얼 가이드는 "실사 영상처럼 현실적인 피부와 조명"까지만 정했다. 두 인물에 같은 질감 기준을 적용해야 하므로 채널 단위로 한 번 정하면 좋다.
- 도윤 리트리버형 레퍼런스 (EP.02용).
