# ANIMAL HOUSE Creative Archive | 화면 기획서 v0.2

작성일: 2026-10-27 (v0.1 → v0.2)
기준 시안: 대시보드 시안 1장(홈) + HTML 시안 v2 (docs/screen-mockup.html). 시안 속 인물·날짜·일러스트는 플레이스홀더로 보고, 실제 데이터는 수인 쉐어하우스 기획(이현, 서도윤)을 기준으로 한다.

## 0. v0.2 변경 요약 (Codex 검토 반영)

| # | 변경 | 근거 (reviews/screen-plan-review.md) |
|---|---|---|
| 1 | 샷 아래에 **생성 시도(GenerationRun)**와 **후보(Variant)** 계층 추가. 확정 클립은 후보 중 선택 | 샷과 확정 클립 사이 과정이 없어 재현·학습 불가 |
| 2 | **프롬프트 조합기(P-01)**와 조합 결과 스냅샷을 MVP로. 고정 프롬프트는 **버전별 본문 보관(PromptVersion)** | 핵심 문제(프롬프트 재조합)를 2차로 미룬 모순 |
| 3 | 관계 변화를 **RelationChange** 엔티티로 분리. 캐릭터 관계와 에피소드는 참조만 | 관계 변화의 원본이 두 곳 |
| 4 | 소재에 **출처·권리 필드**, 게시에 **AI 표기 체크** 추가. 성과는 플랫폼 게시물(Publication) 단위 | 초상권·라이선스·AI 표기 정보 부재 |
| 5 | **백업·내보내기, 소프트 삭제, 참조 중 파일 삭제 금지**를 MVP로 | 백업이 3차로 밀려 있음 |
| 6 | **MVP 축소.** 관계도, 타임라인, 스토리 변화 요약, 알림, 뷰 전환, 최근 본 항목, 성과 분석을 2차 이후로. 홈은 3열 구조는 유지하되 카드를 줄임 | 인물 2명·에피소드 0편 시점에 UI 비용만 큼 |
| 7 | 미정 항목을 **프로젝트 전체 목록(OpenIssue, O-01)**으로. 캐릭터·세계관·장소·채널에 소속 필드로 연결 | 소유 범위가 다른 항목을 같은 배열로 취급 |

반영하지 않고 2차로 기록한 것: 에피소드 단위 연속성 세트(의상·조명·소품 고정)는 개요 탭의 체크리스트로 대체. 플랫폼별 렌더·안전영역 검사는 게시 체크리스트 항목으로만. 프롬프트 블록은 9개가 아닌 4개(캐릭터 / 장소 / 샷 지시 / 공통 규격)로 제한.

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | ANIMAL HOUSE Creative Archive |
| 한 줄 정의 | AI 인플루언서 채널 "수인 쉐어하우스"의 캐릭터·장소·에피소드·생성 결과·게시를 한곳에서 관리하는 1인용 제작 시스템 |
| 주 사용자 | 기획자(채널 운영자) 1인. 협업자는 2차 |
| 핵심 문제 | 생성할 때마다 캐릭터 고정 프롬프트, 장소 프롬프트, 앵커 이미지를 채팅·Notion·로컬 폴더에서 다시 모은다. 샷마다 2~3개 변형을 만들지만 어떤 입력으로 어떤 결과가 나왔는지 남지 않는다 |
| 핵심 가치 | 1) 4블록 프롬프트 조합과 스냅샷 2) 샷 → 생성 시도 → 후보 → 확정의 기록 3) 승인된 레퍼런스와 권리 정보 4) 게시 전 AI 표기 체크 |
| 시안 대비 | 시안은 애니 일러스트·여성 주인공·2024년 날짜를 쓰고 있다. 실제는 실사형 남성 2인이며, 썸네일은 실사 레퍼런스 이미지를 쓴다. 시안의 관계도·타임라인·알림은 2차로 미루고 홈 구조만 가져온다 |

## 2. 정보 구조 (IA)

```
ANIMAL HOUSE
├─ 홈 (H-01)                 작업 시작 화면 (3열, 카드 6개)
├─ 캐릭터
│   ├─ 목록 (C-01)
│   └─ 상세 (C-02)           탭: 기본 / 비주얼 가이드 / 성격·말투 / 관계 / 에피소드 / 소재
├─ 장소
│   ├─ 목록 (W-02)
│   └─ 상세 (W-03)
│   └─ 세계관 규칙 (W-01)    [2차] MVP에서는 설정집 소재(마크다운)로 대체
├─ 에피소드
│   ├─ 목록 (E-01)
│   └─ 상세 (E-02)           탭: 개요 / 샷·생성 / 프롬프트 조합 / 게시
│       └─ 프롬프트 조합기 (P-01)   E-02 안의 패널, 단독 화면으로도 열림
├─ 소재
│   ├─ 전체 (A-01)           이미지 / 영상 / 설정집 / 대사 / 스토리 노트 / 기타
│   ├─ 소재 상세 (A-02)      출처·권리 포함
│   └─ 휴지통 (A-03)
├─ 미정 항목 (O-01)          프로젝트 전체 결정 대기 목록
├─ 설정 (S-01)               프로젝트·스타일 프리셋 / 역할·관계 유형 / 생성 도구 / 백업·내보내기
├─ 전역 검색 (G-01)          ⌘K, 단순 텍스트 검색 (접두어는 2차)
├─ 관계도 (R-01)             [2차]
└─ 타임라인 (T-01)           [2차]
```

좌측 메뉴 순서: 홈, 캐릭터, 장소, 에피소드, 소재, 미정 항목, 구분선, 관계도(2차), 타임라인(2차), 설정. 2차 메뉴는 비활성 표시로 남겨 구조를 미리 보여준다.

## 3. 공통 레이아웃

### 3.1 헤더 (전 화면 고정)

| 영역 | 구성 | 동작 |
|---|---|---|
| 로고 | ANIMAL HOUSE / Creative Archive | 클릭 시 홈 |
| 전역 검색 | ⌘K | 캐릭터·장소·에피소드·소재 이름 검색. 결과 없음 시 "새 ○○ 만들기" |
| 백업 상태 | 마지막 백업 시각 점 표시 | 24시간 이상 지나면 경고색. 클릭 → S-01 백업 |
| 프로필 | 아바타 + 이름 | 계정, 로그아웃 |

알림(종)은 2차. 헤더 배경 이미지는 설정에서 지정 가능하되 기본은 단색.

### 3.2 좌측 사이드바

| 영역 | 구성 |
|---|---|
| 메인 메뉴 | 홈, 캐릭터, 장소, 에피소드, 소재, 미정 항목 |
| 2차 메뉴 | 관계도, 타임라인 (비활성, "2차" 태그) |
| 설정 | 하단 |
| 프로젝트 카드 | 대표 이미지, 프로젝트명 |

최근 본 항목은 2차.

### 3.3 본문 공통 규칙

- 카드 헤더는 "제목 + 설명 한 줄 + 우측 '전체 보기'".
- 빈 상태: "아직 등록된 ○○이 없습니다 + [추가] 버튼".
- 날짜 `YYYY.MM.DD`, 미정은 "예정".
- 삭제는 항상 소프트 삭제. 삭제 전 확인 단계는 화면 안에 인라인으로 둔다(브라우저 confirm 사용 금지).
- 참조 중인 소재(샷·생성 시도·캐릭터 앵커가 가리키는 파일)는 삭제 버튼이 비활성화되고 참조 목록을 보여준다.
- 저장 실패 시 카드 상단에 오류 띠와 "다시 시도". 업로드 실패 시 해당 파일 행에 사유 표기.

## 4. 화면별 상세

### H-01 홈 (작업 시작 화면)

목적: 지금 만들고 있는 에피소드로 바로 들어가고, 막힌 것(미정 항목, 레퍼런스 부재)을 확인한다. 3열 구조는 유지하되 카드는 6개로 줄인다.

| # | 열 | 카드 | 구성 | 동작 |
|---|---|---|---|---|
| 1 | 좌 | 캐릭터 | 캐릭터 행: 아바타, 이름, 종, 레퍼런스 준비 상태(얼굴 앵커 / 시트 / 동물형 각각 ○×), 고정 프롬프트 버전 | 클릭 → C-02. 레퍼런스 미등록이면 × 표시 |
| 2 | 좌 | 장소 | 장소 행: 이름, 앵커 유무, 공통 프롬프트 버전 | 클릭 → W-03 |
| 3 | 중 | 제작 중인 에피소드 | 현재 "제작 중" 에피소드 1편의 샷 보드: 샷별 상태(미생성/후보 검토/확정), 후보 수, 다음 할 일 | 클릭 → E-02 샷·생성 탭. 제작 중이 없으면 "기획" 상태 중 첫 편 |
| 4 | 중 | 에피소드 목록 | 최근 5편: 회차, 제목, 상태, 등장인물 | 클릭 → E-02. 전체 보기 → E-01 |
| 5 | 우 | 미정 항목 | 열린 항목 최대 5건: 제목, 소속(캐릭터/세계관/장소/채널), 막고 있는 에피소드 | 클릭 → O-01 |
| 6 | 우 | 최근 추가된 소재 | 썸네일, 파일명, 유형, 날짜 | 클릭 → A-02 |

홈에서 뺀 것(2차): 관계도 위젯, 에피소드 타임라인, 스토리 변화 요약, 소재 유형별 집계 카드.

### W-02 장소 목록 / W-03 장소 상세

| 화면 | 구성 |
|---|---|
| W-02 | 장소 카드: 대표 이미지, 이름, 상위 장소, 앵커 유무, 등장 에피소드 수 |
| W-03 | 이름, 설명, 상위/하위 장소, 구조 레퍼런스 슬롯(평면도 / 장소 앵커, 승인 상태), 고정 요소·유동 요소 목록, 조명·시간대 기본값, **공통 프롬프트 현재 버전 + 복사 + 버전 이력**, 등장 에피소드, 연결 소재 |

초기 장소: 쉐어하우스(거실, 현관, 주방, 세탁실, 이현 방, 도윤 방), 에이전시 스튜디오, 아파트 산책로. 세계관 규칙(W-01)은 MVP에서 설정집 소재 1건으로 대체한다.

### E-01 에피소드 목록

| 항목 | 내용 |
|---|---|
| 뷰 | 리스트 1종 (칸반 전환은 2차) |
| 항목 | 회차, 제목, 상태(아이디어/기획/제작 중/게시 완료), 등장인물, 장소, 샷 진행(확정 n / 전체 m), 게시 수 |
| 필터 | 상태, 인물, 장소, 시리즈 |
| 액션 | 새 에피소드, 순서 변경(게시 전 에피소드만), 복제 |
| 복제 규칙 | 개요·샷 행동·카메라·프롬프트 블록 참조만 복제. 생성 시도·후보·확정·게시 정보는 복제하지 않는다 |
| 회차 규칙 | 표시 회차는 게시 시점에 고정. 게시된 편의 회차는 순서 변경으로 바뀌지 않는다 |

### E-02 에피소드 상세

| 탭 | 구성 요소 |
|---|---|
| 개요 | 회차, 제목, 상태, 훅, 줄거리, 핵심 관계성, 등장인물, 장소, 습성 태그, 관계 변화(RelationChange 생성·목록), 시리즈, **연속성 체크리스트**(의상·조명·시간대·소품을 에피소드 단위로 적어 두고 샷 생성 시 참조) |
| 샷·생성 | 샷 테이블: 번호, 인물, 장소, 길이, 행동, 감정·반응, 카메라, 자막(이 샷에 걸리는 자막과 시점), 상태(미생성/후보 검토/확정/폐기). 샷을 펼치면 **생성 시도 목록**(도구, 모델, 일시, 입력 스냅샷 보기, 후보 수, 비용 메모)과 **후보 그리드**(썸네일, 길이, 품질 메모, 확정 선택, 폐기). 샷 삽입·삭제·복제·순서 변경 |
| 프롬프트 조합 | P-01 패널. 아래 별도 기술 |

## 8. 미정 사항

- 구현 형태: 웹앱(로컬 실행) vs Notion. GenerationRun·PromptVersion·참조 보호는 Notion으로 구현하기 어려워 웹앱을 권장.
- 파일 저장소: 로컬 폴더 vs 클라우드. MVP는 로컬.
