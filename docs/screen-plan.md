# ANIMAL HOUSE Creative Archive | 화면 기획서 v0.1

작성일: 2026-10-27
기준 시안: 대시보드 시안 1장 (홈 화면). 시안 속 인물·날짜·일러스트는 플레이스홀더로 보고, 실제 데이터는 수인 쉐어하우스 기획(이현, 서도윤)을 기준으로 한다.

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | ANIMAL HOUSE Creative Archive |
| 한 줄 정의 | AI 인플루언서 채널 "수인 쉐어하우스"의 캐릭터·세계관·에피소드·제작 소재를 한곳에서 관리하는 내부 제작 아카이브 |
| 주 사용자 | 기획자(채널 운영자) 1인. 이후 제작 협업자(영상 생성, 편집) 1~3인 |
| 핵심 문제 | 설정이 Notion·채팅·로컬 폴더에 흩어져 있어 생성 프롬프트에 앵커 이미지와 고정 설정을 매번 다시 모아야 한다. 에피소드가 쌓일수록 관계 변화와 소재 위치를 추적하기 어렵다 |
| 핵심 가치 | 1) 캐릭터별 고정 프롬프트와 레퍼런스를 한 번에 복사 2) 에피소드별 샷·프롬프트·게시 결과 관리 3) 관계와 설정 변화 이력 추적 |
| 시안 대비 | 시안은 애니 일러스트·여성 주인공·2024년 날짜를 쓰고 있다. 실제는 실사형 남성 2인이며, 썸네일은 실사 레퍼런스 이미지를 쓴다. 시안의 "주인공/조력자/적대자" 태그는 역할 태그로 채택하되 명칭은 설정 화면에서 수정 가능하게 한다 |

```
ANIMAL HOUSE

├─ 캐릭터
│   ├─ 목록 (C-01)
│   └─ 상세 (C-02)           탭: 기본 / 비주얼 가이드 / 성격·말투 / 관계 / 에피소드 / 소재
├─ 세계관
│   ├─ 세계관 규칙 (W-01)

│   └─ 장소 상세 (W-03)
├─ 에피소드
│   ├─ 목록 (E-01)
│   └─ 상세 (E-02)           탭: 개요 / 샷 리스트 / 프롬프트 / 게시
├─ 소재 관리
│   ├─ 전체 (A-01)           이미지 / 설정집 / 대사 / 스토리 노트 / 기타

├─ 타임라인 (T-01)

```

### 3.1 헤더 (전 화면 고정)

| 영역 | 구성 | 동작 |

| 로고 | ANIMAL HOUSE / Creative Archive | 클릭 시 홈 |
| 전역 검색 | 플레이스홀더 "캐릭터, 장소, 에피소드, 소재를 검색해보세요…", 단축키 ⌘K | 클릭 또는 ⌘K로 검색 모달(G-01) |
| 알림 | 종 아이콘, 미확인 시 점 표시 | 클릭 시 알림 드롭다운. 협업자 추가 전에는 "소재 업로드 완료", "에피소드 상태 변경"만 |
| 프로필 | 아바타 + 이름 + ▾ | 계정, 프로젝트 전환, 로그아웃 |
| 배경 | 시안은 쉐어하우스 외관 일러스트를 헤더 배경으로 사용 | 프로젝트 대표 이미지로 교체 가능. 설정(S-01)에서 지정 |

| 설정 | 구분선 아래 | |

### 3.3 본문 공통 규칙

- 카드 단위 레이아웃. 카드 헤더는 "제목 + 설명 한 줄 + 우측 '전체 보기'" 구조를 유지한다.
- 모든 목록 카드는 "+ 더보기 (n)"로 접고, 전체 보기는 해당 섹션 화면으로 이동한다.
- 빈 상태: 각 카드에 "아직 등록된 ○○이 없습니다 + [추가] 버튼"을 둔다.
- 날짜 표기: `YYYY.MM.DD`. 미정은 "예정"으로 표기한다.

## 4. 화면별 상세

### H-01 홈 (대시보드)

목적: 프로젝트 현재 상태를 한 화면에서 파악하고, 자주 가는 곳으로 바로 이동한다.

3열 구조. 좌: 캐릭터 목록 패널, 중: 관계도 + 3개 요약 카드, 우: 타임라인·변화 요약·최근 소재.

| # | 영역 | 구성 요소 | 동작 / 데이터 |
|---|---|---|---|
| 1 | 캐릭터 목록 패널 | 제목 "캐릭터 목록", "전체 n명", + 버튼, 검색창, 캐릭터 행(아바타, 이름, 역할 태그, 성격 키워드 3개, >) | 행 클릭 → C-02. 주요 인물은 상단 고정·배경 강조. + → 캐릭터 추가 모달. 하단 "+ 더보기 (n명)", "새 캐릭터 추가" 버튼 |
| 2 | 관계도 위젯 | 제목, 설명, 필터 탭(전체/주요 인물/조력자), 전체화면 버튼, 그래프, 범례 | R-01의 축소판. 노드 클릭 → C-02, 엣지 클릭 → 관계 상세 팝오버. 전체화면 → R-01 |
| 3 | 세계관/장소 카드 | 대표 장소 이미지, 장소명, 설명, 하위 공간 썸네일 4개(거실, 현관, 세탁실, 스튜디오 등) | 썸네일 클릭 → W-03. 전체 보기 → W-02 |
| 4 | 에피소드 카드 | 최근 3편: 썸네일, 제목, 한 줄 요약, "관계 변화" 태그 + 관련 인물 | 클릭 → E-02. 상태(아이디어/기획/제작 중/게시) 배지 추가 (시안에는 없음) |
| 5 | 소재 관리 카드 | 유형 5종(이미지, 설정집, 대사, 스토리 노트, 기타) + 개수 + 설명 | 클릭 → A-01 해당 유형 필터 |
| 6 | 최근 에피소드 타임라인 | 세로 타임라인, 회차·제목·날짜·한 줄 요약, 예정 편은 "예정 / 준비 중" | 클릭 → E-02. 전체 보기 → T-01 |
| 7 | 스토리 변화 요약 | 인물 쌍 + 변화 흐름 "1화) 친구 → 2화) 호감 → 3화) 연인" | 관계 이력(R-01)의 최근 4건. 클릭 → 관계 상세 |
| 8 | 최근 추가된 소재 | 썸네일, 파일명, 날짜, 업로더 | 클릭 → A-02. 전체 보기 → A-01 |

우선순위: 1, 4, 5, 8은 MVP. 2, 6, 7은 2차(관계·타임라인 데이터가 쌓인 뒤).

### C-01 캐릭터 목록

| 항목 | 내용 |
|---|---|
| 목적 | 등장인물 전체를 역할·종·상태별로 훑고 상세로 진입 |
| 뷰 | 카드 그리드(기본) / 리스트 전환 |
| 카드 항목 | 대표 이미지, 이름, 나이, 종(도베르만 수인 등), 역할 태그, 성격 키워드, 등장 에피소드 수, 레퍼런스 이미지 유무 |
| 필터 | 역할(주인공/조력자/적대자/미정), 종, 거주지(쉐어하우스/외부), 상태(활성/예정/보류) |
| 정렬 | 역할 우선, 이름순, 최근 수정순 |
| 액션 | 새 캐릭터 추가, 복제, 보관 |

### C-02 캐릭터 상세

이 프로젝트에서 가장 많이 쓰는 화면. 탭 구조.

| 탭 | 구성 요소 | 비고 |
|---|---|---|
| 기본 | 이름, 나이, 성별, 키, 종, 역할 태그, 거주지, 직업, 한 줄 소개, 배경 서사(마크다운), 미정 항목 체크리스트 | "미정 항목"은 설정 전반에서 미확정 사항을 모아 보는 용도. 예: 이현 직함(팀장/사장) |
| 비주얼 가이드 | 인간형 외형 기준(불릿), 동물형 외형 기준, 레퍼런스 이미지 슬롯(얼굴 앵커 / 캐릭터 시트 / 동물형 / 기타), 레퍼런스 우선순위 목록, **고정 프롬프트(한/영) + 복사 버튼**, 장면 프롬프트 틀 | 복사 버튼이 핵심. 레퍼런스 슬롯은 "앵커 역할"을 라벨로 명시 |
| 성격·말투 | 성격 키워드, 호칭(상대별: 도윤→이현 "현이형"), 반말/존댓말, 말버릇, 습성 목록(수인 특성, 체크 가능), 금지 표현 | 습성 목록은 에피소드 작성 시 소재로 끌어다 쓸 수 있게 태그화 |
| 관계 | 상대 캐릭터별 관계 카드: 관계 유형, 현재 상태, 변화 이력(에피소드 기준), 비즈니스 관계(집주인-입주자, 대표-소속 모델) | 한 쌍에 관계 유형 복수 허용 |
| 에피소드 | 등장 에피소드 목록 + 그 편에서의 역할·변화 | E-01 필터 링크 |
| 소재 | 이 캐릭터에 연결된 이미지·대사·노트 | A-01 필터 링크 |

### W-01 세계관 규칙

| 항목 | 내용 |
|---|---|
| 목적 | 세계 설정(수인의 정의, 인간화, 동물형 규칙, 정체 은폐)을 조항 단위로 관리 |
| 구성 | 섹션(세계 기본 / 수인 규칙 / 동물형 전환 / 사회 규칙) > 조항 카드(제목, 본문, 상태: 확정/미정, 관련 에피소드) |
| 액션 | 조항 추가·수정, 상태 변경, 변경 이력 보기 |
| 비고 | "미정" 조항은 홈과 캐릭터 상세의 미정 항목 체크리스트에 함께 노출 |

### W-02 장소 목록 / W-03 장소 상세

| 화면 | 구성 |
|---|---|
| W-02 | 장소 카드 그리드: 대표 이미지, 장소명, 상위 장소(쉐어하우스 > 거실), 등장 에피소드 수. 필터: 상위 장소, 실내/실외 |
| W-03 | 장소명, 설명, 상위/하위 장소, 구조 레퍼런스(평면도·앵커 이미지, 역할 라벨 포함), **고정 요소 / 유동 요소** 두 목록, 조명·시간대 기본값, 장소 공통 프롬프트(한/영) + 복사, 등장 에피소드, 연결 소재 |

초기 장소: 쉐어하우스(거실, 현관, 주방, 세탁실, 이현 방, 도윤 방), 에이전시 스튜디오, 아파트 산책로.

### E-01 에피소드 목록

| 항목 | 내용 |
|---|---|
| 목적 | 에피소드를 상태별로 관리하고 게시 순서를 정한다 |

| 필터 | 상태, 인물, 장소, 플랫폼, 시리즈(소리 반응 시리즈 등) |

### E-02 에피소드 상세

| 탭 | 구성 요소 |
|---|---|
| 개요 | 회차, 제목(가제), 상태, 훅 한 줄, 줄거리, 핵심 관계성, 등장인물, 장소, 사용한 습성 태그, 관계 변화(인물 쌍 + 전→후), 시리즈 소속 |
| 샷 리스트 | 샷 테이블: 번호, 인물, 장소, 길이(초), 행동, 감정·반응, 카메라, 상태(미생성/생성 중/확정), 확정 클립 첨부 |
| 프롬프트 | 자막 타이밍표, 샷별 프롬프트(한/영) 블록 + 복사, 사용된 고정 프롬프트 버전 표시, 편집 메모 |
| 게시 | 플랫폼별 게시일·링크·캡션·해시태그, 성과(조회, 좋아요, 팔로우 전환, 저장) 수동 입력, 댓글 메모 |

샷 테이블은 docs/content-plan.md의 샷 구성을 그대로 담는 구조다. "인물 고정 프롬프트 자동 삽입" 기능은 2차.

### A-01 소재 관리 / A-02 소재 상세

| 화면 | 구성 |
|---|---|
| A-01 | 상단 유형 탭(전체/이미지/설정집/대사/스토리 노트/기타), 그리드/리스트, 필터(인물, 장소, 에피소드, 태그, 업로더, 기간), 업로드(드래그 앤 드롭), 일괄 태그 |
| A-02 | 미리보기, 파일 정보, 유형, 연결(인물·장소·에피소드), 태그, 설명, **앵커 역할**(얼굴 앵커/캐릭터 시트/장소 앵커/없음), 버전 이력, 다운로드, 삭제 |

소재 유형 정의:

| 유형 | 내용 |

## 7. 시안에서 조정이 필요한 점

- 시안의 캐릭터 썸네일은 애니 일러스트다. 실제는 실사 레퍼런스 이미지를 쓰므로 아바타 크롭 규칙(얼굴 중심 정사각형)을 정한다.
- 시안 에피소드 카드에 상태 표시가 없다. 제작 파이프라인 관리를 위해 상태 배지를 추가한다.
- 시안 관계도는 인물 9명 기준이다. 초기 2명일 때의 빈 상태·소수 노드 레이아웃을 따로 설계한다.
- 시안 타임라인은 날짜 기준이다. 옴니버스 형식에 맞춰 회차 기준으로 바꾸고 날짜는 보조 표기한다.
- 시안에 없는 "고정 프롬프트 복사", "앵커 역할 라벨", "미정 항목 체크리스트"는 이 프로젝트의 제작 방식(docs/content-plan.md, docs/visual-doyoon.md)에서 나온 필수 요소로 추가한다.

## 8. 미정 사항

- 구현 형태: 웹앱 직접 개발 vs Notion 템플릿으로 대체. MVP 범위는 Notion으로도 가능하나 관계도·프롬프트 자동 조합은 웹앱이 필요하다.
- 소재 저장소: 로컬 폴더 연동(현재 `visual/`) vs 클라우드 업로드.
- 성과 데이터: 수동 입력 vs 플랫폼 API 연동.
